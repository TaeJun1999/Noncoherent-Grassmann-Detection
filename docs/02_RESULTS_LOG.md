## R3 — MACG base 스케일 법칙 (2026-09-16)

**코드** `code/scale_and_cost.py` part A
**설정** `T ∈ {4,8,12,16}`, `M ∈ {1,2,3}`, `κ ∈ {1,4}`, `c` grid 0.02–3.0 (22점), n=40k

- `c*·T/κ` : 중앙값 **1.78**, 범위 [1.06, 6.00]
- `κ=1`에서 비율 1.06–1.37로 깨끗, `κ=4`에서 흩어짐
- 유도 근거: MACG 지수부 1차 전개 `≈ T·c·tr(XᴴGX)` → `Tc ≈ κ`

**Haar 대비 ESS 이득**

| κ | Haar ESS/n | MACG(c*) ESS/n |
|---|---|---|
| 1.0 | 0.86–0.96 | 0.999 |
| 4.0 | **0.04–0.46** | **0.76–0.98** |

**결론** 기본값 `c = 2κ/T` + (T,M,SNR)당 ESS line search 1회. 고 SNR에서 base 변경만으로 sample efficiency가 5–20배. flow의 기여와 무관하게 성립하므로 ablation #10a가 이미 의미 있는 baseline이다.

**결론 세 가지**

1. 큰 `T, M`이 우리 편이다. exhaustive는 `T²M`, 네트워크는 대략 `T`로 는다 → 헤드라인 설정을 `T=16–32, M=4, B=20–24`로.
2. `d ≤ 64`, NFE ≤ 4. few-step은 선택이 아니라 제약이다.
3. **단일 스트림은 병목이 아니다.** 부하는 subcarrier grid 전체에서만 실재한다. 모든 복잡도 주장에 `n_sc`와 심볼 길이를 명시해야 한다.

**미해결 (gate)** 위 비교는 구조 없는 codebook 기준이다. 구조화 codebook의 효율 demapper는 블록당 10²–10³ MAC으로 제안 방식보다 약 10⁴배 싸다. 정확도 격차 측정이 필요하다 → `00_STATE.md` gate. *(2026-09-17: R6에서 측정 완료. gate 실패.)*

## R6 — 구조화 codebook 효율 demapper 대 exact ML (gate) (2026-09-17)

**코드** `code/cubesplit_gap.py` (라이브러리), `code/sanity.py` (검증), `code/run_ser.py` (SER), `code/run_bler.py` (BLER), `code/p26_center_test.py` (작성만, **미실행**)
**의존성** numpy, scipy. 1코어 3 GB에서 전체 재실행 약 50분 (SER 15분, BLER CS(4,2) 5분, CS(8,1) η≤16 25분, η≤32 25분).

### 설정

Cube-split (Ngo–Decurninge–Guillaud–Yang, arXiv 1905.08745, TWC 2020) 원논문 정의 그대로. `M=1`.

- 신호 모델: `Y = √(ρT)·x hᵀ + Z`, `‖x‖=1`, `h ~ CN(0,I_N)`, `Z ~ CN(0,1)`. **SNR = ρ (채널 사용당, 수신 안테나당).** 블록 SNR은 `ρT`, 즉 `+10log₁₀T` dB.
- 맵 (원논문 12): `t = √((1−e^{−|w|²/2})/(1+e^{−|w|²/2}))·w/|w|`, `w = N⁻¹(a₁)+jN⁻¹(a₂)`. 격자 `A = {(2k+1)/2^{B₀+1}}`. 심볼 (11): `x = [t … 1 … t]/√(1+Σ|t|²)`, `1`은 cell 위치.
- 라벨 (§III-D): cell bits = binary(i−1) `log₂T`개, 좌표 bits = 실수 차원당 `B₀`비트 Gray. `B = log₂T + 2(T−1)B₀`, `K = 2^B`.
- exact posterior 가중치: `exp(κ‖Yᴴx‖²)`, `κ = ρT/(1+ρT)` (원논문 24 = R1의 `κ`).

### 결론

구조화 codebook에서 싼 demapper는 exact ML과 1 dB 미만 차이다. hard decision은 전 설정에서 ≤ 0.6 dB, 10³ MAC 보정 시 ≤ 0.1 dB. soft 출력은 `T=4`에서 ≤ 0.3 dB, `T=8`에서 ~0.7 dB이며 리스트 크기로는 닫히지 않는다. **gate 실패.**

|---|---|---|---|---|

재현성: 같은 점의 R6 (c) 값은 exact 0.0344 / 0.0333, P26 η=16 0.2433 / 0.2589 (900 부호어). 이번 값과 맞는다.

**파생값** (로그가 아니라 계산이다. R6 (c) CS(8,1) 첫 표의 exact 곡선에 log-linear 보간해 "같은 BLER을 exact가 내는 ρ"를 구하고 1.5 dB와의 차를 취했다):

|---|---|---|
| P26-D1 | +0.69 dB | +0.59 .. +0.78 |
| P26-D3 | +0.46 dB | +0.36 .. +0.55 |
| P26-cells | +0.21 dB | +0.03 .. +0.32 |

P26-D1의 +0.69는 R6 (c)가 곡선에서 직접 읽은 +0.68 / +0.73과 일치한다 (환산 방법의 검산). R6 (c) 둘째 표의 exact 곡선을 쓰면 P26-D3 +0.45, P26-cells +0.21.
후보 지표 비용 (후보 수 × `T·N`, R6 (d)와 같은 계수): D1/D3 1.7e4 MAC, cells 1.4e5 MAC. exact LLR 6.4e6의 약 1/46.

**결론** 리스트 중심을 near-ML 점으로 옮겨도 격차는 닫히지 않는다 (+0.69 → +0.46 dB). 남은 격차는 후보 집합이 놓친 posterior mass와 함께 움직인다. η를 두 배로 늘린 효과는 0.05 dB였지만 (R6 c), 서로 다른 `T`개 cell의 리스트를 합치면 +0.2 dB까지 준다. 부호화 동작점의 posterior는 한 점 주변이 아니라 여러 cell에 퍼져 있다.
